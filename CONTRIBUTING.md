# Contributing to VaultForge

Thanks for helping improve VaultForge.

## Development
1. Fork the repository.
2. Create a focused branch.
3. Make your change.
4. Test the app in a current Chromium/Firefox/Safari browser.
5. Open a pull request with a clear description.

## Guidelines
- Keep the app dependency-free where practical.
- Never introduce telemetry that captures generated secrets.
- Preserve cryptographically secure randomness.
- Keep accessibility and mobile usability in mind.
- Avoid committing secrets or credentials.
